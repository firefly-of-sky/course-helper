# Course Helper · 网课助手

视频播放、连续看课与优学院自动答题辅助脚本。当前版本：**5.6.1**。

## 一、适用范围

### 1. 已验证的平台

目前已在 **优学院** 的标准课件页面验证视频播放、跨练习连播和自动答题：

```text
https://ua.ulearning.cn/learnCourse/learnCourse.html
```

自动答题适用于可识别的课件练习，支持单选、多选、判断和普通文本输入控件。独立考试、作业页面、富文本编辑器及字体解密暂未适配。

### 2. 其他平台与反馈

**其他平台尚未完成实际测试。** 脚本包含的域名匹配规则，不代表对应平台的全部功能都可以使用。

如果希望适配其他网课网站，或使用时遇到问题，欢迎[提交 Issue](https://github.com/firefly-of-sky/course-helper/issues/new)。请尽量提供：

- 平台名称、页面类型及不含私人参数的页面地址。
- 浏览器、脚本管理器和脚本版本。
- 复现步骤、预期效果与实际表现；需要时附打码截图。

请勿在 Issue 中提交账号密码、Cookie、访问令牌或个人答题记录。

## 二、使用方法

### 1. 安装脚本

1. 在浏览器中安装 Tampermonkey 等兼容的用户脚本管理器。
2. 打开仓库中的 [`repaired.user.js`](./repaired.user.js)，将完整源码复制到管理器的新脚本中并保存。也可以使用内容相同的 [`repaired.user.txt`](./repaired.user.txt)。
3. 如果已安装同名同 namespace 的旧修复版，进行版本更新；停用原始旧脚本，避免重复运行。
4. 重新打开课件，或保存当前作答后刷新页面。

本版需要手动更新，不会自动下载仓库里的新版脚本。

### 2. 视频播放与连续看课

1. 打开面板的「视频播放」页签。
2. 输入倍速，或选择预设；按需设置静音、自动播放，然后点击「应用播放设置」。
3. 希望视频正常结束后继续播放下一段时，开启「结束后自动下一视频」。
4. 希望先连续看完视频、最后统一答题时，开启 **「只连播视频，暂不答题」**。该模式会同时打开自动播放和自动下一视频，并按课程目录跳过练习与图文、跨章寻找后续视频。

两个连播开关立即保存。最后一段视频结束后会停止，练习仍保留在目录中；之后可以自行进入对应练习答题。遇平台提示、锁定任务或无法确认的目录时会停留，不会绕过平台限制。

### 3. 自动答题

1. 从目录进入需要处理的优学院课件练习。
2. 切到「自动答题」页签，确认识别出的题目数量。
3. 点击「查询答案并自动填入」，查看逐题结果；需要中止时点击「停止」。
4. **填入后请自行核对，再手动提交。** 脚本不会自动提交练习。

### 4. 测试浏览器的倍速上限

当前脚本支持输入 **0.25～16 倍速**，可以在这个范围内自行设置数值，并不只限于预设按钮。

浏览器对媒体倍速也有自己的支持范围。下面的代码检测当前浏览器对 `playbackRate` 属性允许设置的**正向倍速上限**；即使测出更高上限，也不会改变当前脚本的 16 倍输入限制。接口说明见 [MDN：HTMLMediaElement.playbackRate](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/playbackRate)。

**测试步骤：**

1. 在需要测试的桌面浏览器中打开一个普通网页。
2. 按 `F12`，或右键选择「检查」，打开开发者工具的 **Console / 控制台**。
3. 阅读下面的代码，复制到控制台并执行，查看表格及测试结论。

<details>
<summary>点击展开倍速上限测试代码</summary>

```javascript
(() => {
  // 创建独立的测试元素，不加载媒体、不改动页面上的课程视频。
  const video = document.createElement("video");
  const samples = [];
  const accepts = rate => {
    try {
      video.playbackRate = rate;
      return Math.abs(video.playbackRate - rate) < 1e-6;
    } catch {
      return false;
    }
  };

  let supported = 1;
  let rejected = null;
  for (const rate of [1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024]) {
    const ok = accepts(rate);
    samples.push({ 倍速: rate, 允许设置: ok });
    if (!ok) {
      rejected = rate;
      break;
    }
    supported = rate;
  }

  if (!samples[0].允许设置) {
    console.warn("当前环境连 1 倍速都无法正常设置，无法判断上限。");
    return;
  }

  // 在已接受和已拒绝的值之间细化，误差小于约 0.001 倍。
  while (rejected !== null && rejected - supported > 0.001) {
    const mid = (supported + rejected) / 2;
    if (accepts(mid)) supported = mid;
    else rejected = mid;
  }

  const limit = Math.floor(supported * 1000) / 1000;
  console.table(samples);
  console.info(rejected === null
    ? `本次测到至少 ${limit} 倍，尚未找到上限。`
    : `属性允许设置的正向倍速上限约为 ${limit} 倍。`);
})();
```

</details>

这个测试只检查浏览器是否接受属性值，**不代表视频一定能以该速度稳定解码，也不代表平台会按这个速度计入观看进度**。实际播放还可能受到播放器、媒体格式、设备性能和平台规则影响。

### 5. 移动与收起面板

- 按住标题栏空白处拖动，可以移开遮挡页面的面板。
- 点击减号收起；收起后的「网课助手」按钮也可以拖动，点击即可展开。
- 位置会自动保存，刷新后恢复；窗口变化时会限制在可见范围内。
- 点击标题栏的「复位」可恢复到右上角。

## 三、功能介绍

### 1. 视频播放控制

通过浏览器原生 HTML 视频 / 音频接口调整倍速、静音与播放状态，并检测动态出现的媒体。

提供常用倍速预设；新安装默认使用 1 倍速，静音、自动播放和连播选项均关闭。

*实际脚本界面，本地演示页面截图，不包含真实账号与课程信息。*

### 2. 跳过练习的视频连播

脚本先观察视频的正常播放进展，确认自然结束后，再根据优学院课程目录中的任务类型寻找下一个视频。

开启「只连播视频，暂不答题」后，会跳过练习与图文，必要时展开后续章节，然后点击平台现有的视频目录项。练习不会被填写、提交或标记为完成，学习记录仍由平台处理。

这个功能是**连续播放课程视频**，不会把进度条直接拖到结尾，也不会伪造观看完成状态。

### 3. 自动答题的原理

自动答题直接使用 **优学院自身接口返回的答案**，不接入第三方题库。处理流程为：

1. 读取当前练习的题干、题型、选项、题目 ID 和练习页 ID。
2. 利用当前优学院登录会话，向固定的平台答案接口逐题发起查询：

   ```text
   GET https://api.ulearning.cn/questionAnswer/{题目ID}?parentId={练习页ID}
   ```

3. 校验返回结果，将答案与当前题目的选项或输入控件匹配，再自动填入。
4. 在面板显示处理结果，交由使用者核对后提交。

接口无答案、权限不足、题型未适配或无法唯一匹配选项时，会跳过并提示。不能保证所有课程、题目和页面都能查询成功。

*本地模拟题目与答案，仅展示实际界面和填写流程。*

### 4. 面板与数据保存

播放和答题分为两个页签，面板可拖动、收起和复位。设置及位置保存在用户脚本管理器中；没有本地题库导入功能，也不会上传整页 HTML、把认证信息写入仓库或发送给第三方题库。
